## Code editor

**VS Code** — free, huge extension library, works for every language you'll touch as a student.

## Version control

**Git + GitHub** — track your changes and host your project portfolio for free. Every internship application will ask for this.

## Database

**MySQL Community Server** + **MySQL Workbench** — the same tools used in industry, both free.

## Deployment

**Vercel** and **Render** — deploy full-stack projects for free, no credit card required for the basic tier.

## Practice

**LeetCode** (free tier) — for when DSA prep starts.

## Design

**Figma** (free tier) — useful once you start caring about how your projects actually look, not just how they work.

None of these cost anything, and together they cover almost everything you need for a student project — from writing code to showing it off.
